# Notebook guidance

After running the synthetic lab, load the CSV outputs from `outputs/results`.

Suggested notebook cells:

1. Load `synthetic_emergency_demand.csv`.
2. Compare `synthetic_resource_allocation.csv` with `synthetic_equity_audit.csv`.
3. Plot demand versus service ratio by vulnerable zone.
4. Inspect `synthetic_scenario_comparison.csv`.
5. Review the generated Markdown report.

Do not mix real emergency data into notebooks unless proper authorization, data governance, and responder oversight are in place.
