# Emergency planning boundary

This repository is not emergency-response command software.

It must not be used as the sole basis for:

- evacuation orders
- emergency dispatch
- medical triage
- public warning
- law-enforcement action
- shelter admission decisions
- real-time life-safety decisions

Real disaster response requires trained responders, emergency-management authorities, verified field data, incident command processes, legal authority, medical oversight, and public communication governance.
