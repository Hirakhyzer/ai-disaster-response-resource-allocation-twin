# Methodology

This repository uses a transparent synthetic disaster-response pipeline.

1. Generate fictional zones with population, exposure, social vulnerability, access constraints, and infrastructure stress.
2. Generate fictional shelters, hospitals, distribution hubs, emergency operations facilities, supplies, and road links.
3. Forecast emergency demand using exposure, vulnerability, outage probability, mobility access gaps, and scenario severity.
4. Audit capacity pressure for shelters, hospitals, hubs, and staging facilities.
5. Estimate route delays using road damage probability, debris, exposure, road capacity, and scenario severity.
6. Allocate resources using transparent strategy-specific weights.
7. Audit equity gaps by comparing vulnerable-zone service ratios, access risk, and unmet resource needs.
8. Compare response strategies using service ratio, minimum service, equity gap, and review count.

All metrics are planning-support signals and require expert interpretation.
