# Synthetic lab guide

The default pipeline creates fictional zones, facilities, supplies, roads, and scenario settings.

No real disaster data is needed. A typical run creates:

- zone demand forecasts
- capacity pressure scores
- resource shortage summaries
- route delay audits
- resource allocations
- equity review flags
- response strategy comparisons
- a Markdown report
- local figures
- a hash-chained audit ledger

Use synthetic results to test code, reporting, and methodology only.
